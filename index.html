MV・音声合体・分解ツール

FFmpeg未読み込み

1. 動画

mp4 / mov / mkv / avi / webm

2. 音声

wav / mp3 / flac / aac / m4a / ogg / opus

3. サムネイル

jpg / jpeg / png / webp

4. 処理モード

合体 / 分解
作成内容
分解時の入力 分解モードでは動画ファイルだけを使用します。音声欄とサムネイル欄に選んだファイルは無視されます。

5. エンコード設定

MP4 / H.264 / AAC
速度と品質
自動処理 合体時は元動画の音声を選択した音声に置き換えます。サムネイルは選択済みの場合のみ埋め込みます。
GPU利用 現在は無効です。ブラウザ版FFmpeg.wasmでは未対応のため、将来のネイティブ版向け予約機能です。

6. 実行

自動ダウンロード

7. 進捗バー

0〜100%
待機中 0%

8. ログ

リアルタイム表示

処理はすべてブラウザ内で実行されます。大きなファイルでは端末のメモリに余裕を持って実行してください。
